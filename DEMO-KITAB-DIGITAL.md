## 🎓 Use Cases

### Untuk Santri/Mahasiswa:
```
1. Buka Alfiyyah Bab 1
2. Aktifkan terjemahan & footnotes
3. Baca & pahami setiap bait
4. Bookmark bait yang sulit
5. Review bookmark nanti
```

### Untuk Ustadz/Guru:
```
1. Pilih bab yang akan diajar
2. Salin teks Arab untuk materi
3. Gunakan footnotes sebagai referensi
4. Highlight poin penting untuk siswa
```

### Untuk Self-Study:
```
1. Mulai dari Ajurrumiyyah (pemula)
2. Baca dengan terjemahan
3. Perbesar teks jika perlu
4. Bookmark bait untuk hafalan
5. Progress step by step
```
